Hello, world

print is a built-in — no import, no declaration. Strings interpolate with ${...}, and every statement ends with a semicolon: no automatic insertion means no ASI bugs to debug.

hello.sl

Variables & types

let is immutable, var opts into mutation. Types are inferred inside a function body and always written at boundaries — here that's just the annotations on pi and ready, to show the syntax; lives and title infer fine without one.

variables.sl

Functions

func name(params): ReturnType. Recursion is unremarkable — Solis caps call depth at 256 frames, the same limit enforced the same way whether the script is interpreted or compiled ahead of time.

functions.sl

Control flow

Every block is braced — no dangling-else — and for x in xs walks an array directly, with no iterator protocol underneath it.

control-flow.sl

Arrays

len and push are built-ins too, typed loosely so they work on an array of anything — the one place the standard library is weaker than it looks, and an honest trade for not having generics on every function.

arrays.sl

Structs & methods

Structs are values — inline layout, no allocation, no refcount traffic. Fields and methods share one body, C++/TypeScript-style. this needs no receiver parameter, mut func marks a method that writes to it (leave it off and that write is a compile error, not a silent copy), and static func is for methods that need no instance at all.

structs.sl

Enums & switch

Enums are real tagged unions — variants can carry named payload fields. switch is exhaustive: comment out a case below and re-run it to see the compiler name the variant you left out, rather than finding out at runtime.

enums.sl

Null

Reference types may be null. There's no ?. short-circuit yet, but a plain comparison against null works, which is enough to guard a lookup that might not find anything.

null.sl

Modules & stdlib

math and strings are part of the language itself — compiled into the runtime, so import math; needs no file on disk. Everything a module declares is reachable as module.name.

modules.sl

Talking to the host

extern func declares a function the host provides. That's the entire sandbox: a script reaches exactly what's registered and nothing else — no ambient filesystem, no network, no clock, unless the embedder hands one over. This playground registers hostName and roll just so this example has something to call.

host.sl

In a real embedding, a prelude.sl file sitting beside the scripts declares every extern once, so individual plugins don't repeat the host's whole API just to call three functions from it.

What's solid, what's in progress

Solis is a work in progress, and the honest version of that table beats a glossy one:

AreaStatus
Core language — functions, control flow, structs, enums, exhaustive switch, modulessolid
Standard library — math, strings, and the batteries (io/fs/os/time/rand) in a native buildsolid
Host boundary — extern func, the prelude mechanismsolid
null and reference typessolid
Generics, interfaces, weak, arena blocksremoved

Generics, interfaces, weak and arena aren't missing — they were cut from the language on purpose, to keep the compiler small and every remaining hard problem (ARC elision, cycle detection, monomorphising) off the table.

This page only runs examples from the solid row, on purpose — a learning tour that occasionally breaks isn't a learning tour. See design.md in the repo for the full design log, including why each of those decisions was made.
