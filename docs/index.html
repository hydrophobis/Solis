Why not just use Lua?

Lua owns the embedded-scripting niche, and deservedly — a few hundred KB, no dependencies, an API whose stack discipline makes ownership bugs nearly impossible. Solis isn't trying to out-Lua Lua on size. It bets on four things Lua is genuinely weak at:

Sandboxing by construction

A script reaches exactly the functions the host registered — nothing else. No ambient filesystem, network, or clock.

No GC pauses

Reference counting with compile-time elision, not a tracing collector. Deterministic memory for realtime loops.

Rust/Elm-grade diagnostics

A missed switch case is a compile error naming the variant you forgot, not a runtime surprise.

It's just C

The whole toolchain is one C99 binary. An embedding host links a library with no Rust, no cargo, no second toolchain.
